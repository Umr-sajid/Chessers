# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Chessers, please report it responsibly.

**Do NOT open a public issue for security vulnerabilities.**

Instead, please email or [start a private discussion](https://github.com/Umr-sajid/Chessers/discussions) with details.

## Scope

Since Chessers runs entirely in the browser with no backend, the attack surface is limited. However, we take all reports seriously — especially around:

- Cross-site scripting (XSS)
- Malicious FEN/PGN input handling
- Dependency vulnerabilities

## Response Time

We aim to acknowledge reports within 48 hours and provide a fix timeline within 1 week.
